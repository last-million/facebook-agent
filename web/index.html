How production runs (each cycle)

  1. Discovery keeps the candidate pool fed from Walmart deal categories (toys, women's plus, garden, summer, home, kitchen, kids).
  2. Buffer fill (4-at-a-time, CPU-governed): per product it generates the ShopYourLikes link + Mavlynk shortlink + an approved customer-review image. Products with no review photos are skipped for 14 days (auto-retried), so the fill reaches photo-having products.
  3. Autopilot tick (every ~2 min): picks up to Concurrency eligible profiles (past their per-profile spacing) that have ready products and publishes them in parallel — opens staggered 8s apart, throttled by the CPU governor.
  4. Each post is publish-only; then a different random profile with group access adds the first comment on the exact permalink (realism). No access → comment skipped, post kept.
  5. Posts held for moderator approval are approved by a moderator profile (serialized, one at a time, time-bounded).
  6. When the daily cap is reached it prepares tomorrow's buffer. The watchdog restarts the server if it goes down. The Pinterest agent is never touched.
